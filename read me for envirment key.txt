🟢 Scenario 2: API Key Windows Environment Variable me hai (Recommended Setup)

Agar aapne set kiya tha:

setx CL_OTP_API_KEY "abc123xyz" /M


To remove karne ke liye:

🔹 Temporary remove (current session only)

Remove-Item Env:CL_OTP_API_KEY

🔹 Permanently remove (machine level)

[Environment]::SetEnvironmentVariable("CL_OTP_API_KEY", $null, "Machine")


⚠️ IIS restart required:

iisreset
